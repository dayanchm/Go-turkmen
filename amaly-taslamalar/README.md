# Amaly taslamalar

Bu bölümde Go bilimini hakyky programmalar arkaly berkitmek üçin doly işleýän taslamalar ýerleşýär.

## Taslamalar

| Taslama | Dereje | Öwredýän temalary | Ýagdaýy |
|---|---|---|---|
| [Todo CLI](todo-cli/README.md) | Başlangyç | CLI, JSON, faýl, test | Taýýar |
| REST API | Orta | HTTP, middleware, CRUD | Meýilleşdirilýär |
| URL shortener | Orta | HTTP, database, cache | Meýilleşdirilýär |
| Mini blog | Ösen | PostgreSQL, auth, Docker | Meýilleşdirilýär |

Her taslamada işletmek görkezmesi, kod gurluşy, testler we ösdürmek üçin ýumuşlar bolar.
