# Kody tertiplemek we barlamak

Go standart gurallary koduň birmeňzeş we ygtybarly bolmagyna kömek edýär:

```bash
go fmt ./...       # kody formatlaýar
go vet ./...       # ähtimal ýalňyşlyklary tapýar
go test ./...      # ähli testleri işledýär
go test -race ./... # maglumat ýaryşlaryny barlaýar
```

Gysga funksiýalary, düşnükli atlary we anyk ýalňyşlyk habarlaryny ulan. Ýalňyşlygy ýitirme, ony gaýtarmak ýa-da loga ýazmak gerek.
