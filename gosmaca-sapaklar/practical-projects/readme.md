# Amaly taslama pikirleri

Bilimi berkitmegiň iň gowy ýoly kiçi taslama tamamlamakdyr:

1. **CLI hasaplaýjy:** argumentleri oka, amallary ýerine ýetir, nädogry maglumat üçin ýalňyşlyk görkez.
2. **Todo REST API:** döretmek, sanawlamak, täzelemek we pozmak endpoint-lerini ýaz.
3. **URL gysgaldyjy:** uzyn salgyny gysga koda bagla we redirect et.
4. **Howa maglumat CLI-si:** HTTP API-den maglumat alyp, JSON jogabyny görkez.
5. **Mini blog:** ulanyjy, ýazgy, autentifikasiýa we PostgreSQL goş.

Her taslama üçin README, test, konfigurasiýa mysaly we işletmek görkezmesi ýaz. Ilki maglumatlary ýatda sakla, soň maglumat bazasyna geçir.
