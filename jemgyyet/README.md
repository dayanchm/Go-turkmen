## Taslamaňy goşmak

Pull request-de şu maglumatlary görkez:

```markdown
- Developer ýa-da topar:
- GitHub profil:
- Taslamanyň ady:
- Taslamanyň linki:
- Go-nyň ulanylýan ýeri:
- Gysga düşündiriş:
```

Talaplar:

- taslamada Go möhüm rol oýnamaly;
- açyk GitHub/GitLab repositoriýasy bolmaly;
- README ýa-da düşündiriş bolmaly;
- zyýanly, ogurlanan ýa-da spam taslama bolmaly däl.
