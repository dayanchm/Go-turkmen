# Iňlisçe–türkmençe programmirleme terminleri

Sözlügiň interaktiw görnüşi: [go.dayanch.dev/sozluk.html](https://go.dayanch.dev/sozluk.html).

## Esasy terminler

| Iňlisçe | Türkmençe düşündiriş |
|---|---|
| algorithm | meseläni çözýän ädimleriň tertibi |
| variable | üýtgeýji |
| constant | hemişelik baha |
| type | maglumat görnüşi |
| function | funksiýa |
| parameter | funksiýanyň kabul edýän üýtgeýjisi |
| argument | funksiýa geçirilýän hakyky baha |
| return value | funksiýanyň gaýtarýan bahasy |
| array | kesgitli uzynlykly maglumat toplumy |
| slice | üýtgeýän uzynlykly dilim |
| map | açar–baha toplumy |
| struct | meýdanlary birleşdirýän gurluş |
| pointer | ýat salgysyny saklaýan görkeziji |
| interface | method-laryň talaplar toplumy |
| goroutine | ýeňil ýerine ýetiriliş birligi |
| channel | goroutine-laryň maglumat alyş kanaly |
| error | ýalňyşlyk bahasy |
| package | Go faýllarynyň toplumy |
| module | paketleri we dependency-leri birleşdirýän birlik |
| middleware | soragyň aralyk işleýji gatlagy |

## Termin goşmak düzgüni

Her täze termin üçin iňlisçe adyny, türkmençe düşündirişini, kategoriýasyny we mümkin bolsa kiçi Go koduny goş. Sözme-söz terjime düşnüksiz bolsa, gysga düşündiriş ulan.
